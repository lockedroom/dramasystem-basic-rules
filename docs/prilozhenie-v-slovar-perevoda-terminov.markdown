- Episode → эпизод
- Face card → фигурная карта
- Fraught relationships → заряженные отношения
- Game Moderator → модератор (игры)
- Grade / Rank → уровень владения
- Granter → даритель
- Intent → намерение

- Petitioner → проситель

- Role → роль

## Типы действий

- Enduring → выносливость
- Fighting → драка
- Knowing → знание
- Making → ремесло
- Moving → проворство
- Sneaking → скрытность

## Составляющие сцены

- Cast → действующие лица
- Mode → тип сцены
- Setting → место действия
- Situation → ситуация
- Time break → скачок во времени

## Разрешение споров

- Challenging a Plot Jump → оспорить поворот сюжета
- Challenging a Time Jump → оспорить скачок во времени
- Challenging For Novelty → оспорить повторение сцены
- Ducking a Scene → уклониться от участия в сцене
- Crashing a Scene → навязать участие в сцене
